# すべてのすがた図鑑

## フォルダ構成

```text
Personal-Pokedex/
├─ index.html             画面とスタイル
├─ app.js                 表示・検索・個人データ管理
├─ manifest.webmanifest   アプリ表示設定
├─ data/
│  └─ pokemon.csv         図鑑の原本（1,594件）
├─ assets/
│  └─ images/             SVGアイコンなどの画像素材
└─ tools/
   ├─ serve.mjs           ローカル確認サーバー
   └─ verify-data.cjs     開発用のデータ動作確認
```

画像素材は `assets/images/` にまとめています。歯車・鉛筆・色違い・登録・所持・画像なしの各SVGアイコンを格納しています。ポケモン画像はCSV内のURLから読み込みます。

## データの構成

- `data/pokemon.csv`：公開する図鑑の原本。サイトを開くたびに自動読込します。
- ブラウザのlocalStorage：登録状況・所持状況・個人メモのみ保存します。
- 設定画面：個人データのJSONバックアップと復元。CSV読込操作は不要です。

現在の原本には、ご提供の全件CSVから変換した1,594件を収録しています。個人の登録・所持状況とメモは公開CSVから除外しています。既存8件の固定IDを維持し、追加項目にも固定IDを付与しています。今後はこのpokemon.csvを編集し、IDと旧キーを維持してください。

## ローカルで起動

PowerShellを開き、最初にプロジェクトのフォルダへ移動します。コード部分だけをコピーして貼り付け、Enterを押してください。`PS D:\…>` などの入力待ちの目印は入力しません。

```powershell
cd "D:\Project\Personal-Pokedex"
```

Node.jsが使える環境では、続けて次を実行します。

```powershell
node tools/serve.mjs
```

`node` が「認識されません」と表示された場合、このPCではCodex付属のNode.jsを使えます。代わりに次を実行してください。先頭の `&` も必要です。

```powershell
& "C:\Users\kkcho\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" tools/serve.mjs
```

このパスは現在のPC専用です。別のPCではNode.jsの用意が必要です。

`Preview: http://127.0.0.1:8000 (Ctrl+C to stop)` と表示されたら、ブラウザで http://127.0.0.1:8000 を開きます。使用中はPowerShellを開いたままにし、終了するときはPowerShellでCtrl+Cを押します。
Pythonが使える場合は `python -m http.server 8000 --bind 127.0.0.1` でも確認できます。
`index.html` の直接ダブルクリックではCSVを読み込めません。
ブラウザの個人データはアクセス先ごとに分かれます。localhost、127.0.0.1、GitHub Pages間の移動には設定画面のバックアップ・復元を使用してください。

## 原本の編集と更新

1. `data/pokemon.csv` をExcelやCSVエディターで編集します。
2. UTF-8のCSVとして保存します。Googleスプレッドシートで編集してCSVを書き出し、このファイルを置き換えても構いません。
3. ローカルサイトを再読み込みして確認します。CSVが不正な場合は画面に理由を表示します。
4. サイト一式とCSVをGitHub Pagesの公開対象に反映します。利用者は次回の再読み込みで更新データを取得します。

Googleアカウントへの接続やスプレッドシートの公開設定は不要です。公開サイトからローカルCSVを書き換える機能はありません。

### 列のルール

- `ID`：必須・一意の固定ID。半角英数字、ハイフン、アンダースコアを使用します。例：`0003-female`。名前を変えてもIDは変更しないでください。削除したIDを別の項目に再利用しないでください。
- `旧キー`：旧版の個人データやバックアップの移行用。旧版の「全国図鑑No|名前」を記入します。新規項目は空でも構いません。移行後も残してください。
- `全国図鑑No`、`名前`、`画像`：必須列。画像の値は空でも構いません。未設定・読込失敗時は assets/images/hatena.svg を表示します。
- `画像 (色違い)`：空の場合は通常色の画像を使用します。
- `世代`、`性別`、`ソート用番号`、`カテゴリ`、`備考`、`実装 (GO)`など、`ポケ徹`、`進化方法`、`進化系`、`すがた違い`：図鑑の基本情報。現在はCSVの行順で一覧表示します。
- `図鑑登録対象`、`色違い図鑑登録対象`：Yesで登録対象、Noで登録不要。
- `所持可能`、`色違い所持可能`：Yesで所持可能、Noで所持不可。
- 上記4つの対象・可否列は空欄の場合Yesです。個人の登録・所持状態ではなく、全利用者に共通する仕様を表します。
- `進化系`と`すがた違い`は従来どおり名前のカンマ区切りで関連付けます。名前変更時は参照元も更新してください。
- カンマ・改行・引用符を含むセルはCSVの引用規則に従ってください。通常の表計算アプリから書き出せば対応します。

公開CSVには `メモ` や `HOME 図鑑登録`、`HOME 所持状況`など個人情報の列を含めません。旧CSVから移す場合はこれらを取り除き、対象・可否だけを新しい列へ移してください。個人データ列を検出したCSVは読込を停止します。

## 個人データの保存・移行

新規利用時は未登録・未所持・メモなしです。通常色と色違いの登録・所持は独立し、メモも通常色・色違いで別管理です。基本データの更新や名前変更でも固定IDにより保持します。原本から一時的に削除された項目の個人データも保持・バックアップします。

旧版と同じアクセス先で開くと、旧localStorage `pokedex_v1` から登録・所持・メモを移行します。未編集で旧CSVに入っていた個人ステータスも移行します。旧保存データは削除しません。新しい保存先 `pokedex_personal_v2` には個人データのみ記録します。旧版のバックアップ（version 1）と新版（version 2）の両方を復元できます。

旧版でブラウザに取り込んだ図鑑本体は、公開原本には自動で書き出しません。今回ご提供いただいた全件CSVの基本データは原本へ反映済みです。旧キーが一致しない項目や原本に未収録の項目の個人データは保持し、バックアップに含めます。

ブラウザのデータ消去や端末変更に備え、定期的にバックアップしてください。端末間の自動同期はありません。公開先に個人バックアップJSONを置かないでください。

## 現在の操作

- 検索欄とフィルターボタンは画面上部に固定しています。名前・図鑑番号・個人メモを検索できます。
- フィルターは世代・登場作品・カテゴリー・図鑑登録・所持状況・メモの順です。世代・登場作品・カテゴリーは複数選択でき、同じ項目内はいずれかに一致、異なる項目間はすべてに一致する条件で絞り込みます。カテゴリーはCSVのソート用番号の小さい順（カテゴリー内の最小値）に表示します。「条件を適用」で反映し、閉じる・Escで編集を取り消します。
- 色違い表示はフィルターボタンの隣で切り替えます。未登録のサムネイル画像はグレートーンかつ不透明度45%で表示します。
- 詳細カードで登録・所持状況を切り替え、個人メモを入力できます。メモは自動保存され、一覧の鉛筆アイコンで有無を示します。
- 右上の歯車ボタンから設定を開き、個人データをバックアップ・復元できます。

## GitHub Pagesへの配置

公開には index.html、app.js、manifest.webmanifest、data/、assets/ を同じフォルダ構成で配置します。CSVと画像のパスは相対パスなので、リポジトリ名を含む公開URLにも対応します。tools/ はローカル確認・開発用です。個人バックアップJSONや個人情報を含む元CSVは公開対象へ追加しないでください。

検索欄の×でテキスト検索のみを解除できます。フィルターボタン横の×でフィルター条件をすべて解除できます。それぞれ条件があるときだけ表示され、色違い表示は維持します。

詳細カードの前後ボタンと左右キーは、検索・フィルター後の一覧順で移動します。先頭・末尾では対応するボタンが無効になります。関連項目への移動や編集で表示中の項目が絞り込み対象から外れた場合は、一覧の並び順に基づく最寄りの該当項目へ移動します。

## まとめて変更

一覧上の「まとめて変更」を押し、カードを複数選択します。「表示中をすべて選択」も使えます。図鑑登録・所持状況の変更先を指定し「選択した項目に適用」を押すと個人データとして保存します。「変更しない」の項目と個人メモは維持します。通常色／色違いはモード開始時の表示が対象で、選択中は色違い切替を無効にしています。登録不要・所持不可は該当する項目のみ変更しません。検索・フィルターで非表示になったカードは選択を解除します。「選択を終了」で通常の詳細表示に戻ります。

検索欄の下の「関連のポケモンを表示」を有効にすると、名前・番号・メモの検索に一致した項目から、進化系・すがた違いの関連をたどってまとめて表示します。同じ図鑑番号のすがたも含みます。検索が空のときは一覧に影響せず、世代など他のフィルター条件は維持します。詳細カードの前後移動と一括選択もこの検索結果が対象です。

## 個人タグ

詳細カードの「タグ」で自由な名前を入力し「作成して付ける」を押します。既存のタグはボタンで付け外しできます。一つの項目に複数付与でき、通常色と色違いで別々に管理します。既存の共通タグは通常色側に引き継ぎます。タグ名の候補は共通ですが、付与・解除・絞り込み・一括編集は現在の表示色が対象です。作成済みのタグはフィルター末尾に表示し、複数選択時はいずれかに一致する項目を表示します。「まとめて変更」のタグ操作から選択項目へ一括追加・解除もできます。タグは個人データとしてブラウザに保存し、バックアップ・復元にも含めます。通常色・色違いのどちらにも付いていないタグは、詳細カード・フィルター・一括編集の候補から自動で消えます。再利用するときは同じ名前で作成できます。

一覧カードでは名前・すがた名の下に現在の表示色の個人タグを表示します。タグは折り返して表示し、カードの高さは内容に応じて広がります。設定の「一覧にタグを表示」で表示・非表示を切り替えられ、設定はこのブラウザに保存されます。非表示にしてもタグの付与やフィルターは維持します。

一括編集は「まとめて変更」で選択モードに入り、カード選択後に件数横の「一括編集」からウィンドウを開きます。ウィンドウを閉じても選択は保持します。件数・選択モードのボタンはヘッダーに固定しています。

詳細カードはヘッダーとフッターを固定し、本文のみスクロールします。前の項目・色違い表示・次の項目は下部に並び、スマホでも色違い表示のテキストを表示します。

通常色と色違いのメモは独立しています。従来のメモは通常色側に引き継ぎます。メモ検索・有無フィルター・鉛筆アイコンは現在の表示色に対応し、バックアップは両方のメモを含みます。

設定の「タグ管理」では、タグごとに名前とカラーを編集して保存できます。同名タグの変更は通常色・色違いの全項目に反映します。既存の別タグと同じ名前には変更できません。削除すると全項目からそのタグを外します。カラーは一覧・詳細・フィルターに反映し、バックアップにも含めます。古いバックアップは既定色で復元できます。

タグカラーはパステル10色・白・グレーの計12色から選び、保存ボタンで反映します。初期カラーは白です。以前の自由カラーは読み込み時に最も近いパレット色へ合わせます。

タグカラーはパステル10色とグレーの計11色です。初期色および以前の白はグレーになります。一覧のタグは背景を約50%の半透明にし、詳細・フィルターの選択ボタンは白背景とカラー枠で表示します。

詳細カード内でタグを外して未使用になった場合、そのカードを閉じるまでは候補を保持し、付け直せます。前後移動や色違い切替でも候補を維持します。閉じた後は未使用タグを候補から除外します。

一括編集のタグ欄は、選択項目すべてに付与ならチェック、一部のみならマイナス、未付与なら空欄で表示します。マイナスの最初のタップは全解除、次は全付与です。新規タグは一覧下で追加します。タグ変更・追加は「選択した項目に適用」で保存し、ウィンドウを閉じて開き直すと未適用のタグ編集を破棄します。

一覧カードを約0.3秒長押しすると複数選択モードに入り、そのカードを選択します。指を動かしてスクロールした場合は長押し選択を取り消します。一括適用後も選択を保持します。更新や絞り込みで選択項目が非表示になった場合も選択数に含み、編集対象として保持します。「×」で選択モードを終了すると解除します。
