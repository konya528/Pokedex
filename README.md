# Personal Pokédex

Pokémon HOMEの図鑑登録・所持状況を、自分用に記録する非公式のブラウザアプリです。スマートフォン・PCで利用できます。Pokémon HOMEとの自動連携はありません。

## 使い方

- **図鑑を選ぶ**：ページ上部の図鑑名を押し、全国・すがた・言語・各ソフト図鑑を切り替えます。
- **探す**：名前・図鑑番号・タグ・メモで検索し、フィルターで絞り込めます。「関連を表示」を有効にすると、進化系や姿違いも検索結果に含めます。検索・フィルターは各×ボタンで解除できます。
- **記録する**：カードを押して詳細を開き、状態の変更やタグ・メモの入力を行います。変更は自動保存されます。
- **まとめて編集する**：「複数選択」またはカードの長押しで選び、「○件を編集」から状態やタグを一括変更できます。

## 登録・所持状況

一覧の図鑑・言語ボタンを押すと、**未登録 → 登録済み → 所持 → 未登録**の順に切り替わります。登録済みは緑、所持は青で表示します。所持不可の項目では「所持」を選べません。

- **全国・すがた図鑑**：登録・所持状況をそれぞれ独立して記録します。星アイコンで通常色・色違いを切り替えられます。
- **言語図鑑**：ポケモンごとに10言語の状態を記録します。姿・色違いによる区別はありません。
- **ソフト図鑑**：図鑑ごとに状態を記録します。「所持」は、そのソフト出身の個体を現在持っていることを表します。

図鑑の対象や出身ソフトなどの登録条件は、Pokémon HOMEでも確認してください。Pokémon GO図鑑は、GOでの実装有無を問わず全ポケモンを表示します。

全国図鑑の記録は、初回のみ従来の代表の姿の状態を引き継ぎ、その後はすがた図鑑と連動しません。

設定の「全国図鑑の連動」をオンにすると、他の図鑑に登録済みの項目があれば全国図鑑でも登録済みとして表示します（初期設定はオフ）。所持状況は連動せず、オフに戻すと全国図鑑の個別記録を表示します。

## タグ・メモと設定

タグの付与状況とメモは**図鑑別**に保存します。すがた図鑑では、さらに姿別・通常色／色違い別に管理します。

右上の歯車アイコンから、一覧の表示設定やタグ管理を開けます。タグ管理は使用先の図鑑ごとに表示します。タグの名前・カラーは共通のため、変更や削除はそのタグを使うすべての図鑑に反映されます。

## 保存・バックアップ

記録は**使用中のブラウザ内**に保存されます。アカウント登録は不要で、端末・ブラウザ間の自動同期はありません。ブラウザの保存データを消すと記録も失われるため、定期的にバックアップしてください。

1. 設定の「バックアップ」でJSONファイルを保存します。
2. 移行先でこのアプリを開き、設定の「復元」からファイルを選びます。

復元すると、現在の記録をバックアップの内容で置き換えます。ファイルにはタグ・メモも含まれるため、自分で保管してください。

## ローカルで使う

Node.jsを用意し、保存したリポジトリのフォルダで実行します。

```powershell
node tools/serve.mjs
```

ブラウザで [http://127.0.0.1:8000](http://127.0.0.1:8000) を開きます。終了はCtrl+Cです。HTMLファイルを直接開く方法ではデータを読み込めません。
