# すべてのすがた図鑑

ポケモンのさまざまな姿を一覧し、Pokémon HOMEの図鑑登録・所持状況を自分用に記録するブラウザアプリです。スマートフォン・PCのどちらでも利用できます。

## 基本的な使い方

- **探す**：検索欄で名前・図鑑番号・メモ・タグ名を検索できます。フィルターボタンから世代、カテゴリー、実装タイトル、性別、登録・所持状況、タグ、メモの有無で絞り込めます。
- **関連を表示する**：検索語を入力すると「関連を表示」が現れます。有効にすると、検索に一致したポケモンの進化系や姿違いも表示します。
- **記録する**：カードを押すと詳細が開きます。登録・所持状況の変更、タグの追加、自由メモの入力ができます。変更は自動保存されます。
- **色違いに切り替える**：星のアイコンの「色違い表示」で切り替えます。登録・所持状況、タグ、メモは通常色と色違いで別々に管理します。
- **まとめて編集する**：「複数選択」を押すか、カードを約0.3秒長押しして選択を始めます。「○件を編集」から登録・所持状況とタグを一括変更できます。「すべて選択」は表示中の項目が対象です。終了するには右端の×を押します。

未登録のポケモンは画像や文字を薄く表示します。検索やフィルターはそれぞれの×で解除できます。検索条件と色違い表示の状態は、ページを再読み込みしても保持します。

## 表示設定・タグ管理

右上の歯車アイコンから設定を開きます。

- 一覧に実装タイトルやタグを表示するか切り替えられます。
- 「タグ管理」でタグの名前・色を変更したり、タグを削除したりできます。削除すると、そのタグはすべての項目から外れます。

## データの保存とバックアップ

記録した登録・所持状況、タグ、メモは、使用中のブラウザに保存されます。アカウント登録は不要です。端末やブラウザ間の自動同期はありません。

ブラウザの保存データを消去すると記録も失われるため、定期的なバックアップをおすすめします。

1. 歯車アイコンから設定を開き、「バックアップ」でJSONファイルを保存します。
2. 別の端末・ブラウザに移す場合は、移行先で同じページを開き、設定の「復元」から保存したファイルを選びます。
3. 復元すると現在の登録・所持状況、タグ、メモをバックアップの内容で置き換えます。必要なら先に現在のデータをバックアップしてください。

バックアップにはメモやタグも含まれます。自分で保管し、公開リポジトリなどにアップロードしないでください。プライベートブラウズでは記録が残らない場合があります。アクセス先のURLが変わる場合も、バックアップ・復元を利用してください。

## ローカルで使う場合

Node.jsを用意し、このリポジトリを保存したフォルダで次を実行します。

```powershell
node tools/serve.mjs
```

ブラウザで http://127.0.0.1:8000 を開きます。終了するときは起動した画面でCtrl+Cを押してください。HTMLファイルを直接開く方法では図鑑データを読み込めません。

## このアプリについて

Pokémon HOMEの記録を手動で管理するための非公式アプリです。Pokémon HOMEとの自動連携はありません。ポケモンの画像などの権利は、それぞれの権利者に帰属します。
